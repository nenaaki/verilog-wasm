# Verilog との食い違いの記録

[README](../README.md) は使い方を書く場所なので、こちらに「どこがどう違っていたか」「何を承知で違えているか」を残す。[差分テスト](../test/verilog-diff.js)（Icarus Verilog との突き合わせ）で出てきたものが中心。

## 直したもの

いずれも 4 値（`xstate`）を入れた後に見つかったもので、**読んで気づいたのではなく突き合わせて出てきた**。

### `casex` が式の側の `x` を don't care にしていなかった

Verilog の `casex` は「**どちらのオペランド**の `x` も比較から外す」。2 値の頃は式の側に `x` が来ないので「ラベルだけ見れば済む」と実装していたが、4 値ではその前提が崩れる。

```verilog
casex (2'b0x)
  2'b01: …   // 一致する。ビット 0 は式の側が x なので比較しない
endcase
```

### 0 除算が `x` にならなかった

2 値では「復元法の回路がそのまま出す値」（商は全ビット 1）を仕様にしていた。4 値では Verilog と同じ `x` を返せる。

### 算術・大小比較・シフト量の `x` がビットごとにしか広がらなかった

ゲートレベルで桁上げを追うと `4'b001x + 4'b0001` は `0xxx` になるが、Verilog は `xxxx`。演算子ごとの規則は [README の表](../README.md#どの演算子がビットごとでどれがまとめて-xか)にまとめてある。

### `if` の条件が `x` のとき両枝を突き合わせていた

Verilog の手続き的な `if` は **`x` を偽として `else` 側へ行く**。三項演算子 `?:` は「両枝が同じ確実な値なら決まる」で、**同じ「条件」でも規則が違う**。ここは規格を読み込まないと踏む。

### `~&` `~|` を `~` と `&` に割っていた

`~^`（XNOR）は 1 トークンにしてあったのに、同じ理屈の `~&` `~|` が漏れていた。割れると `~(&a)` になり、**`~` が文脈幅を受け取る**:

```verilog
wire [7:0] y = ~|p;   // 8'b1 であるべきところ 8'hFF になっていた
```

**既定の 2 値モードのバグ**で、当時 2475 件あったテストが全部見逃していた —— `~|` を 1 ビットの文脈でしか使っていなかったため。ランダム生成した回路を差分テストに流して初めて出た。

## 承知で違えているもの

直すべきずれではない。差分テストの側をここから外してある。

### 非同期リセットはレベル方式

Verilog は `rst` の**エッジ**で発火するが、この処理系は「`rst` が真のあいだ Q を上書きする」。連続時間を持たないモデルなので、エッジという概念が無い（[README](../README.md#クロックを待たないを-cycle-based-でどう表すか)）。答えが割れるのは 2 つ:

- リセットを保持したまま**リセット値が変わる**（実際の RTL はリセット値に定数を使う）
- **`rst` 自体が `x`**（Verilog では `x` への遷移も `posedge` 扱いになる）

### `eval()` 1 回では下流の組合せ出力が追いつかない

非同期リセットが Q スロットを書くのは `eval` の末尾で、その回の組合せ論理は先頭で読んだ Q を使っている。`assign y = q;` のような下流まで見たいときは `eval()` を 2 回呼ぶ。`step()` / `run()` は末尾に `eval` があるので表に出ない。

### 2 値モードには `x` が無い

`initial` の無いレジスタは 0 から始まる（Verilog は `x`）。0 除算も上記のとおり。**4 値モードはこの差を埋めるためにある。**

## それぞれの網が捕まえられるもの

| 網 | 捕まえられるもの | 捕まえられないもの |
| --- | --- | --- |
| WASM vs 参照実装 | コード生成と参照実装の食い違い | **両方が同じネットリストを見ている**ので、elaborate の間違いは揃って間違う |
| JS の手書きモデル | 演算子の作り方 | モデルもこちらが書いたもの。Verilog の読み違いは映らない |
| **iverilog との差分** | Verilog の意味論そのもの | 生成器が出さない構文 |
| コンパイル 2 回の突き合わせ | インスタンスをまたぐ状態の漏れ | 単体で正しく間違っているもの |

**上 2 つはどちらもこちらが書いた物差し**である、というのが差分テストを足した理由。
